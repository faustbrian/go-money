# Support

Use [GitHub issues](https://github.com/faustbrian/go-money/issues/new) for
reproducible defects, documentation gaps, adoption questions, design
exploration, and bounded feature proposals. Include the module path and
version, Go version, platform, minimal reproduction, expected behavior, actual
behavior, and relevant non-secret logs.

Use the private process in [`SECURITY.md`](SECURITY.md) for vulnerabilities.

Support covers released module versions according to
[`COMPATIBILITY.md`](COMPATIBILITY.md). Only the latest major is supported;
users should reproduce against its latest published patch before reporting a
defect. The `main` branch is development source,
not a supported deployment target.
